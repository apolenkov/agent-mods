# Security policy

This repository holds no code, only a marketplace listing. Report a
vulnerability in a mod privately in that mod's repository:

- agent-shell-watch: [GitHub Security Advisories](https://github.com/apolenkov/agent-shell-watch/security/advisories/new)
- agent-council: [GitHub Security Advisories](https://github.com/apolenkov/agent-council/security/advisories/new)
- agent-compact-advisor: [GitHub Security Advisories](https://github.com/apolenkov/agent-compact-advisor/security/advisories/new)

Do not open a public issue. You will get an answer within 7 days. Each mod's
SECURITY.md says what it does on your machine.
