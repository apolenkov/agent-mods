# Getting help

This repository only lists the mods. Ask where the mod lives:

| Mod                   | Questions, bugs and ideas                                                      |
| --------------------- | ------------------------------------------------------------------------------ |
| agent-shell-watch     | [issues](https://github.com/apolenkov/agent-shell-watch/issues/new/choose)     |
| agent-council         | [issues](https://github.com/apolenkov/agent-council/issues/new/choose)         |
| agent-compact-advisor | [issues](https://github.com/apolenkov/agent-compact-advisor/issues/new/choose) |

Include your Claude Code version (`claude --version`), the mod's version from
`/plugin`, and what you saw.

Security problems: do not open a public issue; see [SECURITY.md](SECURITY.md).
